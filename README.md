# NOWN 🌐

### See what's happening now.

NOWN is a modern, real-time social discovery platform designed to help people discover **events, activities, meetups, deals, communities, and spontaneous experiences happening around them.**

Instead of searching across multiple platforms to figure out what's happening nearby, NOWN brings local activity into one place through a **live discovery feed and interactive map**.

> **Discover your city. Find your people. Join the moment.**

---

## 🚧 Project Status

**Currently in development.**

The project is currently in the **product planning and UI/UX development stage**.

The initial focus is building the core discovery experience, followed by real-time social features, recommendations, organizer tools, and business features.

---

## ✨ Core Concept

NOWN answers one simple question:

> **"What's happening around me right now?"**

Users will be able to discover things happening nearby based on:

* 📍 Location
* 🎯 Interests
* 🔥 Trending activities
* 👥 People they follow
* ⏱️ Real-time activity
* 📅 Upcoming events
* 🗺️ Distance

## 🎨 Design & UI/UX

The design philosophy is modern, clean, and focused on discovery.

Key design principles:

* **Mobile-first** - Designed for iPhone and Android devices
* **Clean & minimal** - Uncluttered interface that prioritizes content
* **Vibrant accents** - Eye-catching purple branding that stands out
* **Smooth animations** - Fluid transitions that make the app feel premium
* **Intuitive navigation** - Easy-to-use interface that requires no learning curve

## 🔧 Technical Foundation

### Tech Stack

* **Framework**: React Native
* **Language**: TypeScript
* **Routing**: Expo Router
* **Styling**: Tailwind CSS
* **Animation**: React Native Reanimated
* **UI Components**: react-native-paper

### Key Technical Approaches

* **Native Performance**: Fully native components for optimal performance
* **Real-Time Backend**: Firebase/Firestore or Supabase for real-time data sync
* **Location-Based Services**: Expo Location for precise geolocation
* **Offline Support**: Local storage for caching activities and offline functionality
* **Performance Optimization**: Lazy loading, virtualization, and image optimization for smooth scrolling

## 📊 Key Metrics & Success Factors

### Key Metrics

* Number of active users
* Number of activities created per day
* User retention rate
* Engagement rate (time spent in app, features used)
* Activity discovery rate (how many users find activities)
* Check-in conversion rate
* Event chat activity
* Social connections made (follows, friendships)
* Business adoption rate (businesses creating events)

### Success Factors

* **Network effect**: More users = more activities = more value
* **Real-time accuracy**: Up-to-date information is critical
* **Personalization**: Relevant recommendations drive engagement
* **Community building**: Active event chats and social connections increase retention
* **Business partnerships**: Local businesses create valuable content
